# I324 – S5 – Votre propre GitLab

Ce dépôt est l'application de tâches que vous allez pousser dans **votre** GitLab, installé dans une VM.

Toutes les étapes sont sur la feuille distribuée en classe. Ce dépôt contient aussi :

| Fichier | Rôle |
|---|---|
| `outils/verifier-gitlab.sh` | Contrôle de la VM gitlab (étape 4) |
| `outils/verifier-runner.sh` | Contrôle de la VM runner (étape 6) |
| `ci/verifier.yml`, `ci/verifier.js` | Contrôle final, lancé par votre pipeline (étape 8). Ne pas modifier. |
